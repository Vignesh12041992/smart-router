# laya-smart-router (pipx)

Installs the `smart-router` command with pipx. It is a thin wrapper around the
`laya-smart-router` npm package, so **Node.js 20+ must be installed**.

```sh
pipx install laya-smart-router
# or straight from GitHub:
pipx install "git+https://github.com/vignesh12041992/smart-router.git#subdirectory=python"

smart-router route "write a python function to sort a list"
```

On first run it installs the Node package into a private folder (no global npm install).
See the main README for all commands.
